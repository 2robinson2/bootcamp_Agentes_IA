# bootcamp_Agentes_IA
Prompt de sistema para um agente de IA de suporte à portaria/recepção: orienta sobre o sistema de portaria, procedimentos internos e falhas simples de software e hardware, sempre com base documental. Inclui regra exclusiva de emergência, classificação de risco, encaminhamento por falta de informação, confidencialidade e transparência.
